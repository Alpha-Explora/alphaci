# Composition packs

* [Pack contract](pack-contract.md) - common headings and status vocabulary.
* [Pack template](pack-template.md) - copyable current-state structure.
* [SaaS pack](saas/) - SaaS composition reference.
* [EDU pack](edu/) - EDU composition reference.
* [Enterprise pack](enterprise/) - Enterprise composition reference.

Pack profiles are generated by `npm run generate:architecture-maps -w @alphaci/web` from the `@alphaci/capability-catalog` package. Each profile lists the same capabilities in the same order. Differences belong in status (`not-implemented` versus `not-applicable`), deployment scope, and explicit non-support. Packs do not create separate API domain implementations, runtime edition branches, or edition-specific route trees.
